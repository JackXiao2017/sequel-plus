Sequel Plus <img alt="Logo" src="https://sequelpro.com/images/logo.png" align="right" height="50">
=======

Sequel Plus is the "sequel" to the longtime macOS tool Sequel Pro.
Sequel Plus is a fast, easy-to-use Mac database management application for working with MySQL/MariaDB & PostgreSQL databases.

If you would like to sponsor Sequel Plus, please sponsor one of our maintainers via GitHub Sponsors!

![Screenshot](https://sequelplus.com/images/browse.png)

Build Instructions
=======

* Install the [latest version of Xcode](https://itunes.apple.com/au/app/xcode/id497799835)
* Install [GitHub for Mac](https://desktop.github.com/) (or [SourceTree](https://www.sourcetreeapp.com/), or […](https://git-scm.com/downloads/guis))
* Click "Clone in Desktop" on the right sidebar of our [GitHub page](https://github.com/sequelpro/sequelpro)
* Open `sequel-plus.xcodeproj`
* Click the `Run` button in the toolbar
* If the above doesn't work, please file a [bug report](https://github.com/sequelpro/sequelpro/issues/new)

Contributing
=======

The best way to help the project is to use our [Release builds](https://github.com/JackXiao2017/sequel-plus/releases) and report any issues (both bugs and missing features) in [the issue tracker](https://github.com/JackXiao2017/sequel-plus/issues). If you want to get more involved, then you can comment on issues written by other people or send us a pull request.

Please see our [Issues page](https://github.com/JackXiao2017/sequel-plus/issues). This lists the issues where we would most like your help. There are simple and difficult tasks there so new contributors should be able to get started.
